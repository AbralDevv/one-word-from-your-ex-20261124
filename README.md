# One Word From Your Ex

Entry for the [One Word From Your Ex](https://make.fun/c/u-brave-eagle-12-one-word-from-your-ex-cfd97ba2) competition on make.fun.

The program writes exactly one word — the word an ex would use to describe the entrant — to `/output/entry.txt`:

> **Preventable**

One word, eleven characters, painfully honest. Run it with `node main.ts [output-dir]`.
